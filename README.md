# AI Phishing & Scam Detector

An educational cybersecurity prototype that detects phishing URLs and scam messages using a basic machine-learning model and rule-based heuristics. Built with Python, Flask, and Scikit-learn.

> **DISCLAIMER:** This is a college educational project. The model is trained on a small sample dataset and is **not production-ready**. Results are for demonstration only and should not be treated as reliable security advice. Always use your own judgement.

---

## What Each File Does

| File | Purpose |
|------|---------|
| `app.py` | Flask application that serves the dashboard and provides the `/api/analyze` API endpoint. Loads the trained model and combines ML predictions with rule-based heuristics. |
| `train_model.py` | Reads the sample CSV, converts text to numbers using TF-IDF, trains a Logistic Regression classifier, prints accuracy, and saves the model. |
| `requirements.txt` | Lists all Python libraries needed (Flask, scikit-learn, numpy, nltk, joblib). |
| `data/sample_data.csv` | Contains 60 labeled text samples (30 phishing, 30 legitimate) used for training. |
| `models/phishing_model.pkl` | The saved trained model generated by `train_model.py`. |
| `templates/index.html` | The dashboard HTML structure with mode selector, input, samples, and results. |
| `static/css/style.css` | Dark cybersecurity theme: black background, green highlights, thin borders, responsive layout. |
| `static/js/script.js` | Handles mode switching, input validation, API requests, loading animations, and result display. |

## Setup Instructions (for VS Code)

### Prerequisites

- Python 3.8 or newer installed on your computer
- VS Code with the Python extension installed
- A web browser (Chrome, Firefox, Edge, etc.)

### Step 1: Open the Project in VS Code

1. Open VS Code.
2. Go to **File > Open Folder** and select the `AI-Phishing-Scam-Detector` folder.

### Step 2: Create a Virtual Environment (recommended)

Open the VS Code terminal (**Terminal > New Terminal**) and run:

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Train the Model

Before running the app for the first time, train the model:

```bash
python train_model.py
```

You should see output showing the number of samples loaded, the test accuracy, and a confirmation that the model was saved to `models/phishing_model.pkl`.

### Step 5: Run the Application

```bash
python app.py
```

Then open your browser and go to: **http://127.0.0.1:5000**

## How the Detection Works

The system combines two approaches:

### 1. Machine Learning (Scikit-learn)
- **TF-IDF Vectorizer:** Converts text into numerical features by measuring how important each word is.
- **Logistic Regression:** A classification algorithm that learns to distinguish phishing from legitimate messages.
- The model is trained on 60 labeled samples (30 phishing, 30 legitimate) from `data/sample_data.csv`.

### 2. Rule-Based Heuristics
For **URLs**, the system checks for:
- Link-shortening services (bit.ly, tinyurl, etc.)
- Raw IP addresses instead of domain names
- The `@` symbol (can redirect to a different site)
- Unusually long URLs
- Security-sensitive words on non-HTTPS connections
- Excessive subdomains or dashes

For **messages**, the system checks for:
- Suspicious keywords (free, winner, urgent, verify, etc.)
- False urgency ("act now", "immediately")
- Requests for sensitive information (passwords, bank details)
- Offers of free items or prizes
- Requests to send money or fees
- Threats of account suspension

The final risk score combines both approaches and maps to a risk level: **Low**, **Medium**, or **High**.

## Limitations

1. **Small dataset:** The model is trained on only 60 samples. A real phishing detector would need thousands or millions of examples.
2. **Text-only:** The model analyzes text content only. It does not check WHOIS records, SSL certificates, or website content.
3. **No real-time updates:** The model does not learn from new threats after training.
4. **English only:** The current samples are in English only.
5. **Educational accuracy:** The accuracy on the test set reflects performance on this small dataset and may not generalise to real-world phishing.
6. **Not a security tool:** This project is for learning and demonstration. Do not rely on it for actual security decisions.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `Model file not found` warning | Run `python train_model.py` first. |
| `ModuleNotFoundError` | Run `pip install -r requirements.txt`. |
| Page does not load | Make sure `python app.py` is running and check the terminal for errors. |
| Port 5000 already in use | Change the port in `app.py` (last line) to another number like 5001. |
